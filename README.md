# Frontend Mentor - REST Countries API

A solution to the [REST Countries API with color theme switcher challenge](https://www.frontendmentor.io/challenges/rest-countries-api-with-color-theme-switcher-5cacc469fec04111f7b848ca) from Frontend Mentor.

## Features

* View all countries
* Search for countries
* Filter countries by region
* View detailed information about each country
* Navigate to border countries
* Light and dark mode
* Responsive design

## Built with

* React
* Next.js
* TypeScript
* Tailwind CSS

## What I learned

This was my first project using React, Next.js and Tailwind CSS. I learned about:

* React components, props and state
* Client and Server Components in Next.js
* Next.js routing
* Responsive layouts with Tailwind CSS
* Dark mode
* Managing state between components
